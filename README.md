# MEGA PALAYOK 5000X – FUN EDITION

A complete, playable, single-player Filipino-themed slot game built with React, TypeScript, Tailwind CSS, and Vite.

**This is a personal entertainment project only.**  
It uses **fictional virtual coins**. There is **no real-money gambling**, no deposits, no withdrawals, no payments, and no cash prizes.

## Features

- 5-reel, 3-row slot machine with 20 paylines
- Original symbols: Golden Palayok, Golden Sun, Mango, Golden Coin, Gumamela, Fiesta Bell, Wild, Scatter
- Wild symbol substitution
- Scatter triggers Free Spins (10 free spins for 3+ scatters)
- Random MEGA JACKPOT event (up to 5000× virtual multiplier)
- Adjustable bet, Auto-spin, sound toggle
- Win animations, particle bursts, celebration overlays
- Responsive design (mobile & desktop)
- Progress saved in localStorage
- Fully client-side – no backend, no login

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide React (icons)
- Web Audio API (procedural sound effects)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Import the repository in [Vercel](https://vercel.com).
3. Vercel will detect Vite automatically.
4. Deploy.

The included `vercel.json` handles SPA routing.

Alternatively:

```bash
npx vercel
```

## Game Rules (Summary)

1. Select a bet amount.
2. Press **SPIN** (or enable **AUTO**).
3. Match 3 or more identical symbols on a payline from left to right.
4. **Wild (⭐)** substitutes for any symbol except Scatter.
5. **3+ Scatters (🎁)** award 10 Free Spins.
6. A very rare random event can trigger the **MEGA JACKPOT** (up to 5000× your bet in virtual coins).

All payouts are in virtual coins only.
